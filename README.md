# أُفق — Ufuq TV

**أُفق** لانشر عربي للتلفاز، بدون إعلانات أو تحليلات، من تطوير **M7MD929**. يجمع تطبيقاتك المفضلة، والساعة والطقس، وصور سلطنة عُمان في واجهة زجاجية تعمل بالريموت.

الإصدار الحالي **1.9.5**، رقم البناء **15**. يستهدف أجهزة **Android TV وGoogle TV** المبنية على Android 8 / API 26 فأحدث. اختُبر على Xiaomi MiTV-MOOQ1 بنظام Android 10؛ يختلف دعم تعيين الواجهة الرئيسية حسب الشركة وإصدار النظام، ولم يُختبر على جميع الطرازات.

**تريد أن يفتح زر الهوم أُفق؟** ابدأ من **إعدادات أُفق ← تعيين أُفق كواجهة رئيسية**، ثم اختر **أُفق ← دائمًا** إذا ظهر الاختيار. إذا لم يظهر أو بقيت واجهة الشركة تفتح، اتبع [دليل ضبط زر الهوم حسب نوع الجهاز](docs/HOME-SETUP.md).

## الميزات

- تشغيل التطبيقات وترتيب حتى ثمانية تطبيقات مفضلة، مع دعم الريموت والعربية.
- بطاقة الساعة والتاريخ والطقس أعلى اليمين، وأدوات صغيرة عمودية بأيقونات بيضاء داخل مستطيل زجاجي على اليسار.
- قوائم زجاجية ومعرض صور مصغرة، مع انتقالات خلفية متلاشية.
- 30 صورة من سلطنة عُمان تعمل دون إنترنت؛ 25 صورة بدقة 3840×2160 وخمس للهجر بدقتها الأصلية، مع مصادر ورخص كل صورة.
- شاشة توقف تستخدم مجموعة الصور نفسها. يمنع التطبيق انطفاء الشاشة أثناء ظهوره؛ إعدادات طاقة الجهاز منفصلة.
- طقس Open-Meteo، مع عبري كموقع افتراضي تقريبي للهجر وإمكانية تغيير المدينة.
- مؤثر قرد اختياري: قفزات وتلصص من زوايا الشاشة. نسبة مستقلة لكل فرصة، من 0 إلى 100%، وعدد فرص من 1 إلى 60 في الساعة؛ الافتراضي 2% وفرصة واحدة. لا يوجد ظهور فوري أو تعويض للفرص الماضية.

## البناء على Windows

المتطلبات: JDK 17 أو أحدث، Android SDK Build Tools 36.1.0، ومنصة android-36.1. لا توجد حاجة إلى Gradle أو مكتبات Java خارجية.

```powershell
.\build.ps1 -JdkPath 'C:\path\to\jdk-17' -SdkPath 'C:\path\to\Android\Sdk'
```

الناتج: `build/Ufuq-TV.apk`. يمكن تخصيص إصدار الأدوات والمنصة بالوسيطين `-BuildToolsVersion` و`-PlatformVersion`.

**التوقيع:** هذا المستودع ينشئ مفتاح تطوير جديدًا في مجلد `signing/` المستبعد من Git. لا يحتوي مفتاح توقيع النسخة المثبتة على التلفاز. APK الناتج بهذا المفتاح لا يمكن تثبيته كتحديث فوق النسخة الأصلية؛ يلزم المفتاح الأصلي المحفوظ خارج المستودع لإنتاج تحديث مطابق. لا تحذف نسخة التلفاز أو بياناتها من أجل تجربة بناء التطوير.

## التثبيت والاستخدام

ثبّت APK بالطريقة المعتادة على Android TV ثم افتح أُفق. يمكن تخصيص التطبيقات والخلفيات من أدوات الواجهة. لضبط الواجهة الافتراضية، راجع [دليل زر الهوم](docs/HOME-SETUP.md): يتضمن إعدادات الجهاز، والاتصال عبر ADB، والتحقق من النتيجة، وحالة شاومي المختبرة، واستعادة الواجهة الأصلية. لا ينفذ برنامج البناء تغييرات على التلفاز.

القرد يحتاج إذن العرض فوق التطبيقات وتشغيلًا صريحًا من المستخدم؛ تظهر خدمة أمامية يمكن إيقافها. لا توجد صلاحية كاميرا أو ميكروفون أو خدمة إمكانية وصول. يستقبل التحكم عبر ADB أوامر يحميها إذن النظام `DUMP`، والخدمة نفسها غير مصدّرة.

## التحقق

ثُبّت الإصدار الأصلي 1.9.5 على تلفاز MiTV-MOOQ1 بتاريخ 23 أكتوبر 2026، وتحقّقنا من الإصدار وتطابق بصمة APK. اختُبرت القوائم والسلايدرات والتنقل بالريموت وحفظ الإعدادات على محاكي Android TV / API 29. لم يكتمل فحص القوائم لهذا الإصدار على التلفاز الحقيقي بسبب استخدام الريموت بالتزامن مع الفحص.

توجد اختبارات Java مستقلة للحسابات وجدولة الظهور وهندسة الحركة في `tests/`:

```powershell
.\tests\run-checks.ps1 -JdkPath 'C:\path\to\jdk-17'
```

## الصور والحقوق

انظر [مصادر الصور ورخصها](assets/credits.txt) و[بيانات الصور](assets/photos.json). تحتفظ الملفات برخصها الفردية ونسبتها إلى أصحابها، بما فيها شروط المشاركة بالمثل حيث تنطبق. بعض صور الهجر حقوقها محفوظة لمصادرها وليست تحت رخصة حرة. لا يمنح وجود الملفات في المستودع ترخيصًا إضافيًا لإعادة نشرها.

رسم القرد مولّد باستخدام ImageGen. لم تُضف رخصة مفتوحة للكود تلقائيًا؛ اختيار رخصة النشر متروك لمالك المشروع.

## البيانات والخصوصية

الصور والمفضلة والساعة تعمل دون إنترنت. يحتاج الطقس والبحث عن المدن إلى الإنترنت؛ تُرسل إحداثيات المدينة المختارة إلى Open-Meteo، ويُرسل اسم المدينة إلى خدمة البحث عند استخدامها. لا يحتوي التطبيق خدمات إعلانات أو تحليلات. إعلانات التطبيقات المفتوحة، مثل YouTube، تخضع لتلك التطبيقات.
